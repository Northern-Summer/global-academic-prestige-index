本次从固定 Wikidata 2026-10-26 数据流的 80,966 行断点继续。实际读取在 180 秒解析窗口结束，原始压缩字节经过内存解压而未落盘：457,310,208 字节、174,536 行、4,688 个教育与任职双属性候选，另有单独 ORCID 候选。前置状态为 268,435,456 字节、80,966 行、3,088 个双属性候选。此前的一条超大或异常记录仍保留拒绝计数；没有删除或提高其证据等级。

这只是 103,565,615,653 字节来源的部分前缀，不是完整上游校验，不是完整世界统计。候选行不直接写人才履历事件，后续须由官方 API 独立获取结构化证据；同一 Wikidata 的不同渠道不算独立来源。

当前发现队列因此增至 Wikidata 5,862 个，其中 4,262 已处理、1,600 待处理；ORCID 1,915 个，其中 1,677 已处理、238 待处理，包含原六条异常。这组队列状态不是当前线上冻结评分的输入身份；线上仍绑定已有 18,864 条履历事件的冻结版本。

## 修复及证据

旧实现会在较短重读时覆盖最长压缩前缀的字节计数；打开失败甚至写入零与空哈希。后续采集以这个值扩大窗口，可能反复停在既有断点之前。现在数据库保留最长已读取前缀的字节数和匹配 SHA-256，当前命令结果仍单独报告本次读取字节数。行前缀校验、去重、上游全量校验、证据标准和错误状态保持。

以 Git HEAD 中的旧模块在内存执行两个原反例，两者均触发断言失败；新版 discovery 专项 10 项通过，包括原有校验失败、截断、前缀篡改、重复运行和来源变化。首轮反例测试的模块替换夹具未同步 patched iterator，产生一项 KeyError 与一项错误失败；已修正测试控制并保留该日志，没有把它算成产品缺陷复现。

证据：`python-prefix-baseline-confirmed-20261030.log`、`python-prefix-focused-20261030.log`、`discovery-stream-progress-20261030.json`。全量回归与发布结果在对应 Actions 和最终 settlement 中记录；本文件不预先宣称其已通过。

原始数据没有落盘。数据流进程已经正常结束，无后台下载。保持既有 2 GiB 总预算、256 MiB 预留、512 MiB 解析预算；保留私人冻结输入、失败记录、未完成候选与历史恢复证据。独立第三方红队仍待落实。
