# GAPI external-review handoff

Status: **Pending; no independent third-party review has been performed.**

Review two tracks independently. Research/governance: measurement/causal limits,
direction, evidence provenance, independent versus copied claims, award attribution,
coverage/English/regional/discipline/size bias, privacy and reuse rights. Software:
hostile XML/tar, URL/redirect and dependency risks, budget and process interruption,
personal-data leakage, production manifest integrity, deterministic reproduction.

For the complex-system pass examine self-reinforcing prestige loops, incumbency and
selection incentives, coverage delays, adaptive hiring networks, concentrated source
failures, source starvation, incomplete institutions being confused with weak ones,
writer liveness and fairness. No causal effect is asserted by a network score.

Freeze the reviewed Git commit, source lock, private structured-input hashes (without
publishing person trajectories), configuration and release SHA256SUMS. Reviewers must
be independent of implementation/major contributions and disclose conflicts. Every
finding needs scope, severity, evidence, disposition and retest status. P0/P1 require
fix and independent retest; P2 require an explicit disposition. Internal test results
and this checklist are not a third-party pass.

Reproduction: follow docs/STREAMING.md; run Python unittest/pytest, npm test, execute
the supplied hostile-input fixtures and rebuild from an explicitly selected real
release manifest. Run tests/browser-real.cjs with an existing Playwright/browser.
Compare byte hashes in the release manifest, not screenshots or the CI badge.

Use `python scripts/verify-public-release.py` for a stdlib-only independent
implementation of the public graph-to-score replay. It imports no canonical GAPI
ranking code and needs no personal database. It checks hashes, probability mass,
scores and stored ordering. It does not validate the underlying personal facts.
`python -m gapi.ood` executes bounded deidentified pressure fixtures; see docs/OOD.md.

Known remaining gates are incomplete global source enumeration, independent
official-profile corroboration, unresolved identity crosswalks, other award
families, and full real-data discipline/English deletion analyses. Nobel official
award-time label shares are separately observable, while ROR identity matches stay
candidates. Annual archive metadata is available but no large archive is required
or downloaded; the active pipeline is finite-response API ingestion. Two external
reviewers, their identities/conflicts and independent retests have not been supplied.
Any formal-global-ranking approval is withheld.
