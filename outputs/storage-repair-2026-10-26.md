## 已实施的存储边界

- ROR、OpenAlex、美国招聘样本三个入口共用 `src/gapi/storage.py`。
- 默认在项目外的临时目录处理原料，正常返回和可展开的 Python 异常都会清理本次临时目录。
- `GAPI_SCRATCH_DIR` 支持指定项目外的工作盘目录；未设置时仍使用系统临时目录，不能宣称已自动迁移到 D 盘。
- 显式持久缓存或 checkpoint 路径位于项目目录中时，入口拒绝执行；解析路径后检查，避免 `..` 绕过。
- `data/real/` 被 Git 忽略，防止本地原料、派生数据或清单意外进入普通 Git 提交。公开发布仍须按来源许可选择产物。
- 修复了扩展网络节点集遗漏无边雇主的问题；该问题此前导致敏感性分析测试发生 KeyError。

## 剩余边界

进程被强制终止或断电时，Python 临时目录上下文无法保证执行清理。显式选择的持久缓存按断点续跑语义保留。当前机制也不等于完整的磁盘配额或可处理任意规模数据的流式管线；大规模全球数据导入仍需分块处理、容量预算和检查点设计。当前样本不能称为完整全球统计。
