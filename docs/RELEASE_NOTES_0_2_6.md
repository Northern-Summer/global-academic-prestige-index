# GAPI 0.2.6 — 全球历史观测与持续采集

本版是公开真实观测版本，尚未完成独立第三方双轨审查，不是正式全球排名。持续采集、历史来源完整处理和世界人员总体覆盖是三个不同的进度。

## 数据范围

网页纳入已完成全文件枚举与校验的 Easy ORCID 2023.6 full 历史来源：扫描 17,152,673 行，保留 2,473,948 名两侧履历人员的私有结构化投影。其中 425,076 人贡献 798,879 条去重关系，聚合为 487,234 条机构边。

网络包含 62,103 个机构标识，其中 23,313 个通过精确外部标识对齐 ROR，另外 38,790 个仍待解析。标识数量不等于已确认的独立机构数量。普通就读、缺少日期和未完成学位不会被自动补为博士或毕业事件。历史来源不代表当前全球人员完整普查，也不能与正在采集的 ORCID / Wikidata 人数直接相加。

历史网络 PageRank 在 61 次迭代收敛，L1 差为 9.581539358314347e-13，概率质量为 0.9999999999999987。奖项、综合分数和正式名次继续显示缺失。公开文件仅提供机构聚合；原始压缩包、个人履历输入及人员匹配队列不发布。

## 工程改进

- 严格流式采集与有界批次；HTTPS 连接复用，保留原来的 TLS、访问规则、频率限制及失败退避。
- 独立来源按本次调用实际服务时间分配处理机会，避免慢来源因固定批次轮转占据大部分时间。该调度已经测试，真实网络吞吐收益仍待后续调用验证。
- SQLite 读写争用回滚未完成成员并保留候选，不把本地争用记成来源不可用。
- 当前网络评分使用有界的私有输入投影，避免为评分复制整个历史大库。此快照不代替历史全库灾备。
- 单文件评分默认直接输出确定性的 `.json.gz`，显式 `--out outputs/result.json` 仍支持普通 JSON。压缩不会改变解压后的 JSON 字节。
- 完整网络按机构聚合切片供浏览器按需读取；概览只影响显示，评分仍使用全部有效边。保留现有字体和纸色视觉设计。

## 验证与边界

本地 Python 回归 319 项通过，覆盖来源校验、断点、重复输入、方向、质量守恒、争用恢复、来源故障隔离以及 gzip 与原 JSON 字节一致性。真实历史单文件产物由 71,324,258 bytes 压缩至 6,847,299 bytes，完整反解哈希一致，释放 64,476,959 bytes；重复核验未改动压缩文件及其修改时间。

发布前还需通过现有机构聚合评分独立实现重算、前端测试、生产构建及发布来源核验；GitHub Actions 的生产浏览器检查是自动部署的前置条件。内部测试、内部代理审查和独立实现的算术复算均不等于独立第三方审核。最终 CI 与站点部署状态以 GitHub 的本次运行和线上版本清单为准。

采集继续使用 D 盘任务目录，新增数据预算 2 GiB、预留 256 MiB、进程内存上限 512 MiB。达到容量边界必须保存有效断点；不会静默抽样、降低证据标准或自行增加云账户及费用。
