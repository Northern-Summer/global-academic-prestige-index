# 离线 OOD 压力测试

执行 `python -m gapi.ood`，标准输出为可保存的确定性 JSON 报告。
在 PowerShell 中从项目根目录先设置 `$env:PYTHONPATH='src'`。
`python -m gapi.ood --measure` 另外输出运行时间和采样到的最大进程驻留内存；
该遥测随运行变化，不属于确定性报告。失败不变量使命令退出码为 1；
时间、内存或采样失败会抛错，不能写成通过。

这些夹具全部为去个人化的合成测试数据，只用于验收生产规则，不能进入真实排名。
模块不连接互联网、不打开任务目录或真实个人数据库，SQLite 使用 `:memory:`，
不写数据库、原始资料或报告文件。报告读取并散列自身和相关规则模块，
随机顺序种子由夹具定义、规则文件哈希和标准化规则哈希共同派生。
报告同时记录各组实际事件输入哈希，方便识别规则或夹具变化。

| 场景 | 输入与指标 | 验收含义 |
| --- | --- | --- |
| 多语言学位 | 12 个已完成标签、10 个未完成或未知标签；按阶段统计关系 | 已完成标签正确分层，未知及未完成学位不被提升 |
| 重复与替代证据 | 64 次跨来源重复注入；比较边权、去重关系数、删源后关系数 | 相同稳定人员关系不重复放大，剩余证据可重建关系 |
| 同名不同 ID | 3 个同名稳定人员键、仅 1 人履历完整；误联接数 | 不依赖显示姓名拼接个人履历 |
| 单源低证据注入 | 256 条 unresolved 事件、2 条未提交成员事件 | 低证据不改变基准网络；缺失分数保持 null，单源不能获正式名次 |
| 密集博士后 | 同一人同一机构 128 条博士后经历 | 仅 1 条 postdoc 关系，不产生博士学位 |
| 日期不足与逆序 | 缺毕业年、缺入职年、入职早于毕业 | 不补造年份和先后关系 |
| 删源边界变化 | 重叠任职因删源解除冲突 | 固定网络报告过滤边；扩展网络另报新节点，分别保持概率质量 |
| 地区与规模 | 分组机构图、某行整体放大 1,000 倍、删源、地区平衡先验 | 行归一化不受整行规模影响；报告分数漂移和名次位移 |
| 方向、孤立、极端权重 | 正反边、双向边、64 个孤立节点、越界边、溢出/NaN/Inf/负权重 | 奖励培养机构；有效矩阵质量守恒；非法权重拒绝 |

单次运行预算为 10 秒和 128 MiB **整个进程**驻留内存，复用任务层的内存采样规则。
检查发生于场景边界、每 64 个夹具事件及分析器调用的检查点。
这是有界小夹具的协作式门禁，不是操作系统硬内存限制或精确峰值监控。
在已占用很多内存的宿主 Python 进程中运行可能触发预算；独立 CLI 更适合复现。

这些测试只说明指定输入下的程序行为。它们不估计真实全球误合并率、漏合并率、
整体数据覆盖、不同地区公平性、跨学科准确率或未知缺失机制。
本报告不替代真实数据 OOD 检验、官方页面独立核验或独立第三方双轨红队。
地区分组为夹具标签，行规模放大测试也不代表现实机构规模校正已经解决。

验证命令：`python -m pytest tests/test_ood.py tests/test_global_analysis.py tests/test_career_normalization.py tests/test_ranking.py -q`。
