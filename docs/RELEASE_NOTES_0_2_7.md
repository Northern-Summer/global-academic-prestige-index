# GAPI 0.2.7 — 修复中文缺字

0.2.6 的托管 Linux Chrome 截图暴露出中文缺字：字体名称和加载状态检查通过，但系统没有足够的中文回退字体。此版沿用英文 Playfair 斜体、400 字重宋体标题和纸色背景，补齐 649 个界面、所选公开数据及浏览器国家地区译名使用的中文与标点字形。两个本地 WOFF2 子集共 123,088 bytes，浏览器不依赖外部字体请求。

中文子集也用于正文、导航和等宽标签的回退。拉丁字体不变；当前字形集合不保证覆盖未来新增名称和所有世界文字。字体保留 SIL Open Font License，来源 URL、代码点与哈希记录在 `web/fonts/cjk-coverage.json`。

新增静态字符覆盖与文件哈希测试，并在真实浏览器中把页面中文逐字渲染到画布，与缺字方框比较。字体加载成功不再代替字形可见性检查。局部 Windows 浏览器检查通过 516 个当前页面中文字符，三种字体族均未发现缺字；最终 Linux 结果以本版 CI 为准。

本版不改变评分、数据切片、来源许可和采集断点，也不改变尚待独立第三方双轨审查的研究预览定位。0.2.6 的原失败截图与测试结果保留用于对照。

第一次 Linux 字形检查还发现 190 个由 `Intl.DisplayNames` 动态生成的地区译名字形缺失，CI 拒绝部署。字体语料与静态测试现已包括该动态来源。失败运行 41173134281 保留；最终发布必须经过修正后的同一检查。
