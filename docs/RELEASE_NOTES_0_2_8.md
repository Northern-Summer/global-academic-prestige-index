# GAPI 0.2.8 — 更新全球公开履历观测

本次调用正常结束时，私有最小结构化库共有 101,915 条教育、研究训练及任职事件、28,739 人。年度 ORCID 档案仍未读取成功；本次新增来自公开 API 和 Wikidata。事件、贡献人、机构目录和可评分机构采用不同口径，不能互相替代。公开切片的最终数量与输出哈希以所附 release manifest 为准。

历史 Easy ORCID 2023.6 全量观测保持独立，不混合两套来源的名次和分母。网页仍只提供真实机构聚合；个人轨迹、匹配诊断与未核验候选不公开。

## 本版修复

- 聚合文件和清单使用独占临时文件、同步写入和原子替换。中断不损坏旧文件，不覆盖其他未完成的恢复文件；相同输出不重写。清单在数据文件写好后更新。
- 监控副本补齐重试键索引，避免对每个候选重复扫描重试表。真实监控已在 30 秒时限内运行成功。
- 采集以来源累计服务时间分配下一批，继续遵守单下载流、单写入者、原有限频和失败隔离。实际新调度的吞吐以本版运行记录为准，不以合成时钟测试宣称实网提速倍数。

## 数据与资源边界

D 盘任务目录、2 GiB 总预算、256 MiB 预留和 512 MiB 进程上限不变。原始压缩包、XML、HTML 和个人 JSON 不落盘。四组有界历史样本的分块压缩回读通过，但不足以证明整库迁移能够容纳；未改写或删除历史表。

这是公开观测版本。全球总体完整覆盖未知；当前候选队列尚未清空。独立外部研究方法与软件安全两轨审查待落实，正式排名与缺失奖项的综合分数不以本版代替。

评分的磁盘检查现依据实际写入量，内存使用另行检查；不再为只读计算虚设 64 MiB 磁盘工作区。旧的 17 份机构切片已逐份无损归档并验证原始 SHA-256，释放 31,979,427 bytes；原始内容仍保存在 Git 历史，当前切片与私有输入不动。归档清单位于 `outputs/HISTORICAL_AGGREGATE_COMPACTION_028.json`。
