This update adds 105,548 public education and employment events from ORCID and Wikidata. The frozen input now contains 560,472 events associated with 150,776 internal person keys across 162 country and region codes. Network scores are available for 3,145 institutions. Of the input events, 498,266 remain unresolved; input counts therefore do not represent verified careers or qualifying talent-flow relationships. Input, configuration and output hashes are recorded in the release manifest. The 2023 historical dataset remains separately labelled.

Scores describe observed talent-flow relationships. Coverage is incomplete, and independent external review is pending. Award and composite scores remain missing where supporting evidence is insufficient. Public downloads contain institution aggregates, without individual career trajectories.
