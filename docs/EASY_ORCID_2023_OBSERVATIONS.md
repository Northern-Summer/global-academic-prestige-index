# Easy ORCID 2023：批量真实履历观测

这是历史公开履历的独立观测视图。它不是当前全球人员普查，也不是通过第三方审查的正式排名。暂未合并到线上版本。

## 来源和范围

[Easy ORCID 2023.6](https://zenodo.org/records/13333068) 发布于 2024 年 8 月，是 ORCID 公共数据的派生整理。发布者对部分机构做了 ROR 对齐，并标准化了部分教育名称。它与 ORCID API 不构成两份独立证据。

首个网络使用固定的 `records_hq.jsonl.gz`：662,112,167 字节，MD5 `e18decdd695473e5c6b040f699e63d04`。完整流式读取的 SHA-256 为 `2bd64683a62eb3bbb9e865e729fdfe4754e74b28655b1b021edca0ef6739b67a`。HQ 的选择条件是至少一个可对齐 ROR 的教育机构、雇主，或一篇 PubMed 收录论文；这种筛选本身存在覆盖偏差。

完整发布文件 `records.jsonl.gz` 已流式枚举、导入并通过长度、gzip 和上游 MD5 核验：920,836,363 字节，SHA-256 `376d3cfa6085678dd65289dca2a91d948124d8e685c9480c94f269b95fb609e4`。全文件共 17,152,673 行，1 行超过大小限制；2,496,836 行同时含教育和任职。全部 2,306,992 条 HQ 投影都在完整文件中得到内容精确匹配，另导入 166,956 条投影。相同投影直接复用存储，不复制原料或增加重复关系。

## 机构身份的限制

网络包含 60,861 个机构标识节点，其中 23,301 个已通过固定 ROR 目录取得规范名称和国家或地区，37,542 个 Ringgold 标识与 18 个 GRID 标识尚未完成规范机构对齐。

**60,861 不能写成已消歧的大学总数。** 未对齐标识可能与已知机构指向同一对象，也可能是科研机构、医院或其他单位。系统保留它们在观测网络中的作用，并显示身份待确认；不依靠名称相似自动合并。已确认节点分布于 209 个国家或地区代码，这不能转写为人员国籍或各地人员覆盖率。

所有节点的正式名次都缺失，因为这批派生数据没有独立核验声明。来源的完整校验只验证读取了指定文件，不验证个人自报学历和任职的事实真实性。来源中没有保留的声明者信息明确标记为未知。

## 本地复现

```powershell
python -m gapi census-easy-orcid --max-seconds 1800
python -m gapi ingest-easy-orcid --max-seconds 1800
python -m gapi rank-easy-orcid
python -m unittest discover -s tests -v
```

任务配置和来源必须先冻结。每次恢复重新读取 gzip 并核对已提交投影，不支持任意压缩字节跳转。原料不落盘；压缩投影留在外部任务目录，公开输出仅含机构级聚合。命令共用 2 GiB 总预算、256 MiB 预留和 512 MiB 进程内存上限。索引临时排序与 JSON 导出同样受预算约束。

输入和运行证据见 `configs/easy-orcid-2023-hq.json`、`outputs/EASY_ORCID_BATCH_ACCEPTANCE.json` 与回归日志。真实全量重算已验证机构级文件逐字节一致；后续元数据改进的文件哈希以最新验收记录为准。

正式发布前仍需完成完整来源范围审计、机构消歧缺口披露、更多稳健性场景、前端接入与生产验证，以及独立第三方双轨审查。

分块结果在 `outputs/easy-orcid-web/manifest.json`，与旧的 HQ 单文件结果分开保存。完整机构表、49 个关系分块和概览共 22,172,183 字节；最大单文件 11,122,267 字节。概览仅取前 2,000 条强关系，全部 487,234 条边仍在分块中，不影响评分的网络边界。公开导出不包含逐人轨迹；运行证据在 `outputs/EASY_ORCID_FULL_ACCEPTANCE.json` 和 `outputs/EASY_ORCID_FULL_WEB_IDENTITY.json`。

分块数据已接入本地前端及生产构建：机构表支持搜索、国家与身份筛选、分页及 CSV；选择机构后按需读取全部直接关系。三维概览只显示有限切片，分数始终来自完整网络。地区颜色取自固定 ROR 元数据，未知地区保留灰色；地区字段不参与评分。上述字节数为接入地区字段前的历史验收值，当前文件身份及大小以选中清单为准。

本地与生产浏览器测试覆盖加载、字体、筛选、键盘、直接关系、分块失败、WebGL 降级及移动端。尚未部署本批构建；更多参数情景、与其他来源的独立核验和外部双轨审查仍待完成。文件完整性验证不构成个人履历事实核验或独立第三方通过。
