This release fixes two acquisition progress issues. Discovery now reports selected candidates separately from newly inserted candidates, so duplicate identifiers do not inflate reported additions. A discovery source paused by a server deadline can resume within the same collection run after that deadline expires, while other sources continue. Server backoff and request limits remain in force.

The published observation snapshot is unchanged from v0.2.36: 657,184 education and employment events associated with 176,844 internal person keys across 162 country and region codes. Of these events, 583,386 remain unresolved. Collection continues separately; newly collected records are not included in this release's scores.

All 442 Python tests passed locally. Deployment acceptance also requires the hosted build and production browser checks. Ranking methods, eligibility rules, typography and network rendering limits are unchanged.

Scores describe observed talent-flow relationships, with incomplete coverage. Independent external review remains pending. Award and composite scores remain missing where supporting evidence is insufficient. Public downloads contain institution aggregates, without individual career trajectories.
