# GAPI 0.2.9 — 给持续采集保留更多空间

本版保留 0.2.8 的公开机构切片和评分口径，更新私有冻结输入的存储支持。网页观测数据仍为 101,915 条事件、28,739 人；本轮维护时，采集库已推进到 108,473 条事件。后台新增记录不会冒充已经发布的分数。

15 份私有结构化输入快照由 gzip 直接流式重压缩为 XZ，释放 43,064,085 bytes（约 41.1 MiB）。不生成未压缩 SQLite 工作副本；每份输入的原始 SHA-256 不变。完整校验后才退役旧压缩副本，重复运行不改写结果；没有删除历史输入、履历表或来源证据。

新读者兼容 SQLite、gzip 和 XZ。XZ 解码限制字典内存为 32 MiB，每次最多输出 1 MiB，仍执行任务总容量和进程内存门禁。截断、尾随内容、错误哈希、恢复文件冲突与预算不足均拒绝。旧固定版本的复算仍可先在预算内解压，再核验原始哈希。

维护命令使用已有独占写锁：`gapi compact-frozen-inputs --codec xz --filenames HASH.sqlite`。2 GiB 总预算、256 MiB 预留、512 MiB 进程上限和原料零落盘约束不变。一次压缩改善不意味着有限空间可以容纳任意增长的历史；仍需按每轮实测决定续采和发布边界。

325 项 Python 回归通过。真实完整迁移、回放与质量检查证据记录在本轮工作区报告；公开评分的独立算术验证和浏览器验收继续由 CI 执行。独立外部双轨审查尚未完成，本版不是正式全球排名。
